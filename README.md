# พอร์ทัลรายวิชา 10801322

หน้าเว็บนี้ดึงรายการไฟล์ PDF (จากโฟลเดอร์ Google Drive "Week NN") และการบ้าน (จาก Google Sheet) ผ่าน Apps Script

## ไฟล์สำคัญ
- `assets/config.js` — ชื่อวิชา โลโก้ ข้อความประกาศ ลิงก์ Apps Script
- `assets/style.css` — สี ฟอนต์ ขนาด (แก้ตัวแปรสีด้านบนสุดของไฟล์)
- `index.html` — โครงหน้า

## ขึ้นเว็บด้วย GitHub Pages
1. สร้าง repository ใหม่ (Public) ใน GitHub
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (Add file → Upload files)
3. Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / `(root)` → Save
4. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อบัญชี>.github.io/<ชื่อ repo>/`
